# Política de Privacidade — Youtube Tools Remastered

Última atualização: 12 de maio de 2026

## 1. Coleta de dados

A extensão Youtube Tools Remastered não coleta, transmite, vende nem compartilha dados pessoais dos usuários com o desenvolvedor ou com terceiros.

## 2. Armazenamento local

Algumas preferências e informações de uso são salvas exclusivamente no dispositivo do próprio usuário, por meio do localStorage do navegador. Isso inclui:

- Configurações de resolução, velocidade e volume do vídeo
- Preferência de modo de exibição (expandido/normal)
- Configurações de filtragem de conteúdo (ocultar vídeos assistidos, Reels, Mix)
- Lista de IDs de vídeos marcados como visitados

Esses dados nunca saem do dispositivo do usuário e são utilizados apenas para restaurar as preferências entre sessões. O usuário pode apagá-los a qualquer momento limpando os dados do site no navegador.

## 3. Recursos de terceiros

A extensão carrega uma fonte de ícones diretamente dos servidores do Google Fonts (fonts.googleapis.com) para exibir os ícones da interface. Essa requisição é feita diretamente do navegador do usuário ao Google, estando sujeita à Política de Privacidade do Google. O desenvolvedor desta extensão não tem acesso a nenhum dado resultante dessa comunicação.

## 4. Permissões

A permissão activeTab é utilizada exclusivamente para aplicar as preferências do usuário na aba ativa do YouTube. Nenhuma informação da aba é coletada ou armazenada remotamente.

## 5. Contato

Em caso de dúvidas sobre esta política, entre em contato pelo repositório oficial da extensão.
